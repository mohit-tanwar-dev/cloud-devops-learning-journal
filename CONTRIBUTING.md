# Contributing to Cloud & DevOps Learning Journal

Thank you for your interest in contributing to this learning journal! Contributions, additions, corrections, and shared notes on cloud architecture and DevOps practices are highly welcome.

## Guidelines

1. **Folder Structure:** Place new notes under the appropriate directory (`docs/cloud/`, `docs/devops/`, or `notes/`).
2. **Formatting:** Use clear Markdown syntax, including headings, code blocks, and references where applicable.
3. **Pull Requests:** Open a pull request against the `main` branch with a clear description of the added or updated concepts.
