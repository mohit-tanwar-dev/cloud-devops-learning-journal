# Contributing to Cloud & DevOps Learning Journal

Thank you for your interest in contributing to this learning journal! This repository is primarily a personal collection of notes and resources. However, suggestions, corrections, and additions are welcome.

## How to Contribute

*   **Suggestions/Corrections:** If you find errors, have suggestions for improvement, or want to add a new topic, please open a GitHub Issue.
*   **Additions:** If you wish to contribute new notes or resources, please open a Pull Request.

## Contribution Guidelines

*   Maintain a clear and concise writing style.
*   Organize notes according to the suggested folder taxonomy (e.g., `docs/cloud/aws/`, `docs/devops/docker/`).
*   Ensure accuracy and provide references where appropriate.
*   All contributions should align with the repository's focus on Cloud and DevOps learning.
